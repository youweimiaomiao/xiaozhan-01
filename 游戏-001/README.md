# 土豆兄弟 · 前5波复刻（教学项目）

用 Godot 4.5.1 + GDScript 复刻《土豆兄弟》(Brotato) 的**前 5 波**玩法。
目的：作为 git / Godot / 游戏开发的学习项目，所有数值集中在 `data/game_data.gd`，方便边玩边改。

## 一、怎么运行

**方式 A：编辑器运行**
1. 打开 Godot 4.5.1 编辑器 → 「导入」→ 选择本文件夹里的 `project.godot`
2. 按 `F5` 运行

**方式 B：直接运行（无头验证 / 命令行）**

```bash
# 用你自己的 Godot 路径
godot --headless --path . -- --smoke   # 无头自测：12倍速自动跑完5波，打印结果
godot --path .                          # 正常打开游戏
```

## 二、操作说明

- **移动**：WASD 或方向键
- **攻击**：全自动（瞄准场上最近的敌人开枪），不用按
- **波次**：每波有时间限制，时间到且敌人清空 → 进入商店
- **商店**：花材料买武器（最多 6 把）和道具；「刷新」重新抽商品（费用递增），「锁」让某个商品刷新时保留；点「开始下一波」继续
- **升级**：击杀得经验，经验满 → 暂停 → **4 个属性选项选 1 个**
- **材料**：绿色菱形，走过去自动吸附；波次结束自动收集剩余材料
- **失败**：生命 ≤ 0；**胜利**：活过第 5 波

**建议按这个顺序读代码**：`game_data.gd`（先认识数值表）→ `player.gd`（最直观）→ `enemy.gd` → `main.gd`（流程和UI）。

## 五、教学版简化说明（与原作不同处）

1. **没用手摆场景**：整个游戏只有一个 `main.tscn`，其余节点全部用代码创建——方便 git diff 和命令行开发，也少一个要学的东西。
2. **没用物理引擎**：碰撞全是 `distance()` 圆形判断，几行就能看懂。
3. **画面全部代码绘制**：`_draw()` 画圆画矩形，零外部素材，专注逻辑。
4. 属性做了取舍（见上表），道具效果做了数值简化（如「疤痕」只保留加血、去掉了吸血）。
